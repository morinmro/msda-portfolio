# D210: Representation and Reporting

An interactive Tableau dashboard that combines the WGU churn dataset with an external Kaggle broadband-access dataset. It includes 11 visualizations (maps, ranked lists and more), state and service-type filters, and 6 KPIs (churn rate and adoption of streaming, security, phone and other services).
