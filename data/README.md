Other public datasets live with the project that uses them: UCI Sentiment Labelled Sentences (D213), FRED electricity prices (D214) and a state abbreviation lookup (D211).

## Not included: WGU coursework datasets

Several projects use fictional datasets that Western Governors University provides to students for coursework. They aren't redistributed here. The notebooks are committed with their outputs, so every result, table and chart can still be read on GitHub without the data.

To re-run these notebooks, place the WGU files at these paths:

| Path | Dataset | Used by |
|---|---|---|
| `data/churn_raw_data.csv` | Telecom customer churn, raw (10,000 records) | D206 |
| `data/churn_clean.csv` | Telecom customer churn, cleaned (10,000 records × 50 columns) | D207, D208, D209, D210, D212 |
| `D212-data-mining-2/data/teleco_market_basket.csv` | Online-store transactions (7,501 baskets) | D212 Task 3 |
| `D213-advanced-data-analytics/data/teleco_time_series.csv` | Daily telecom revenue, 730 days | D213 Task 1 |
